# 🌌 بوت ومنصة تواصل وألعاب خيال (Khayal Super-App)

منصة متكاملة وعصرية تعمل كـ **Super-App** داخل **تلجرام (Telegram)**، تجمع بين بوت تواصل ذكي، تطبيق ويب مصغر (Telegram Mini App) يضم **لعبة الطيارة (Crash/Aviator)**، **صالة ألعاب ومباريات مباشرة ضد خصوم أونلاين**، **مشغل راديو FM حي مع مسجل صوتي**، **متجر ونظام شحن نقاط**، و**مكالمات صوت وفيديو مباشرة** مشفرة بتقنية WebRTC.

## 🌟 الأقسام والمميزات الرئيسية في منصة خيال

### 1. 🚀 لعبة الطيارة (Crash / Aviator)
- **مبدأ اللعبة:** يضع اللاعب رهاناً من نقاطه، تقلع الطائرة النيون ويتصاعد العداد والمضاعف (1.00x ... 2.50x ... 10.00x).
- **سحب الأرباح (Cash Out):** يضغط اللاعب على زر السحب قبل أن تنفجر الطائرة ليكسب رهانه مضروباً في المضاعف الحالي!
- **انفجار الطائرة:** إذا انفجرت الطائرة قبل السحب يخسر الرهان.
- **مؤثرات صوتية بصرية حية:** أصوات الإقلاع والانفجار مولدة بمحرك Web Audio API، مع شريط لعرض نتائج الجولات السابقة.

### 2. 🎮 قسم الألعاب والبحث عن خصم (Games Hub)
- **لعبة X-O التنافسية:**
  - **لعب فردي:** تحدَّ الذكاء الاصطناعي لتنمية مهاراتك.
  - **البحث عن خصم أونلاين (Online Matchmaking):** نظام بحث مباشر يربطك بلاعب حقيقي داخل منصة خيال مع رهان نقاط حقيقي (الفائز يحصد الجائزة كاملة 🏆).
- **تحدي سرعة النيون (Reflex Rush):** لعبة سرعة ردود الفعل لجمع النقاط خلال 20 ثانية.

### 3. 📻 راديو خيال FM ومسجل الصوت (Live Radio & Recorder)
- **بث مباشر حقيقي 24/7:**
  - 📖 إذاعة القرآن الكريم - القاهرة
  - 🕋 إذاعة نداء الإسلام - مكة المكرمة
  - ⭐ نجوم FM 100.6
  - 🌍 مونت كارلو الدولية
  - 🎵 روتانا FM
  - 📰 سكاي نيوز عربية
  - 🌙 محطة خيال Chill & Lo-Fi للاسترخاء
- **مؤثرات التردد البصرية (Visual Equalizer):** أمواج صوت تفاعلية تنبض مع البث.
- **مسجل الصوت الفوري:** إمكانية تسجيل مقاطع صوتية وإعادة الاستماع إليها.

### 4. 💎 نظام النقاط ومتجر الشحن (Points & Store)
- **رصيد افتراضي وترحيبي:** يحصل كل مشترك جديد على **500 نقطة مجانية** فور انضمامه.
- **🎁 مكافأة يومية مجانية:** زر استلام هدية يومية (+100 نقطة) كل 24 ساعة.
- **باقات شحن النقاط:**
  - 📦 باقة البداية: 1,000 نقطة (1.00$)
  - 🚀 باقة المحترفين: 5,000 نقطة (4.00$)
  - 👑 باقة النخبة: 15,000 نقطة (10.00$)
  - 💎 باقة خيال الملكية: 50,000 نقطة (25.00$)
- **نظام موافقة الإدارة التفاعلي:** عند طلب المستخدم شحن أي باقة، يصل إشعار مباشر للأدمن في تلجرام مع زرين تفاعليين: `[✅ موافقة وشحن النقاط]` و `[❌ رفض]`. بمجرد الضغط يُشحن رصيد المستخدم تلقائياً ويصله إشعار تهنئة!

### 5. 📞 مكالمات خيال المباشرة (WebRTC P2P)
- مكالمات صوتية ومرئية (فيديو) مباشرة ومشفرة تعمل داخل تلجرام بنقرة زر.
- تحكم كامل: كتم المايك، إيقاف الكاميرا، وقلب الكاميرا للهواتف.

### 6. ✉️ بوت التواصل الذكي وإدارة المشرفين
- تحويل كافة رسائل المستخدمين وصورهم وتسجيلاتهم الصوتية للمشرفين.
- **الرد السريع:** يرد المشرف بـ (Reply) مباشر على الرسالة في تلجرام، ليقوم البوت بنقل رده فوراً للعميل.
- ميزة الإذاعة العامة لجميع المستخدمين (`/broadcast`).
- حظر وفك حظر المستخدمين (`/ban` و `/unban`).
- شحن نقاط لأي مستخدم يدوياً عبر الأمر: `/addpoints <user_id> <amount>`.
- إحصائيات المنصة الحية (`/stats`).

## 📱 أوامر البوت المتاحة للمستخدمين والمشرفين

| الأمر | الوظيفة |
| :--- | :--- |
| `/start` | تشغيل البوت وفتح القائمة الرئيسية الفاخرة |
| `/points` أو `/balance` | عرض رصيد النقاط وخيار الشحن السريع |
| `/daily` | استلام المكافأة اليومية المجانية (+100 نقطة) |
| `/crash` | فتح لعبة الطيارة مباشرة |
| `/games` | فتح صالة الألعاب والبحث عن خصم |
| `/radio` | تشغيل راديو خيال FM |
| `/call` | بدء مكالمة صوت وفيديو مع الإدارة |
| `/addpoints <id> <pts>` | *(مشرف)* إضافة أو خصم نقاط من أي مستخدم |
| `/broadcast <text>` | *(مشرف)* إرسال إعلان لكافة المشتركين |
| `/stats` | *(مشرف)* عرض إحصائيات المستخدمين والنقاط والمكالمات |
| `/ban <id>` / `/unban <id>` | *(مشرف)* حظر أو إلغاء حظر مستخدم |

## 🚀 التشغيل السريع محلياً

```bash
# تثبيت الحزم
pip install -r requirements.txt

# إعداد المتغيرات
copy .env.example .env
# ضع BOT_TOKEN و ADMIN_IDS في ملف .env

# تشغيل النظام
python main.py
```

## 🌐 النشر المجاني 24/7 على السحابة (Render)

1. **ارفع التحديث إلى مستودعك على GitHub:**
   ```bash
   git add .
   git commit -m "إضافة لعبة الطيارة وقسم الألعاب وراديو FM ومتجر النقاط"
   git push origin main
   ```
2. ادخل إلى **Render.com** وأنشئ **Web Service** جديدة مربوطة بالمستودع.
3. أضف متغيرات البيئة:
   - `BOT_TOKEN`
   - `ADMIN_IDS`
   - `BASE_URL`: رابط موقعك من Render (مثال: `https://khayal-app.onrender.com`)
4. سيقوم Render بنشر البوت وتطبيق الويب تلقائياً وسيعمل 24 ساعة مجاناً!
